# Social Media Addiction Prediction

## Overview
This project predicts the level of social media addiction among students based on
their daily usage patterns and lifestyle indicators. The system uses machine learning
for data analysis and model training, and a rule-based decision system for reliable
and interpretable predictions.

---

## Dataset
- Source: Kaggle
- Type: Student social media usage dataset
- Key attributes:
  - Age
  - Average Daily Social Media Usage (hours)
  - Sleep Hours Per Night
  - Mental Health Score
  - Academic Performance Impact
  - Conflicts Over Social Media
  - Addiction Score
