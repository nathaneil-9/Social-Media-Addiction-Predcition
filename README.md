# Social Media Addiction Prediction using Machine Learning

## Dataset
The dataset used in this project was sourced from Kaggle and contains
student social media usage and behavioral attributes.

## Objective
To predict the level of social media addiction among students using
machine learning classification techniques.

## Technologies Used
- Python
- Scikit-learn
- Streamlit
- Pandas & NumPy

## How to Run
1. Install dependencies  
   pip install -r requirements.txt

2. Train the model  
   python train_model.py

3. Run the application  
   streamlit run app.py

## Output Classes
- 0 → Not Addicted
- 1 → Mild Addiction
- 2 → Severe Addiction
